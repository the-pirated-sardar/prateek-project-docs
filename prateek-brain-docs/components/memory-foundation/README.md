The Memory Foundation turns authorized source observations into privacy-treated, provenance-rich, rebuildable L1–L5 memory while preserving L-1 originals and durable H authority. It includes local persistence, access control, queues, filesystem availability semantics, semantic processing, graph/active memory, and runtime supervision.

**Status:** B1 and B2 are closed. Runtime hardening and foundation contracts are accepted.
